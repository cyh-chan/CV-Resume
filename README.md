# Resume

This repository contains the LaTeX source code for my professional resume, maintained as a version-controlled document.

The resume provides an overview of my academic background, research experience, professional appointments, and competencies, with an emphasis on statistics, statistical machine learning, and quantitative research.

## Overview

The resume is structured around the following sections:

- **Education** — Academic qualifications and educational background.
- **Professional Experience** — Research, teaching, engineering, and industry appointments.
- **Research Experience** — Selected research projects and methodological contributions.
- **Competencies** — Programming languages, software proficiency, and spoken languages.

## Compilation

The resume is written in LaTeX and can be compiled using a standard LaTeX distribution.

For local compilation using `pdflatex`:

```bash
pdflatex resume.tex
```

Replace `resume.tex` with the name of the main LaTeX source file.

## Maintenance

This repository is periodically updated to reflect changes in academic qualifications, research activities, professional experience, and competencies.
